# Temporal Concept Dynamics in Diffusion-based Text-to-Audio Generation

This repository contains work from my 10-day research project during my Master in Data and AI at Institut Polytechnique de Paris. For more details, refer to the report [`Temporal_Concept_Dynamics_in_AudioLDM2.pdf`](Temporal_Concept_Dynamics_in_AudioLDM2.pdf).

The code is based on the implementation of [AudioLDM2](https://github.com/haoheliu/AudioLDM2.git).

**Note:** The `log/intermediates` folder, which contains intermediate latent files, is not included in this repository due to its large size. To generate these files, run `run_prompts.py`.
